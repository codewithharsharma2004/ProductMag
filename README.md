# ProductMag

[![Website](https://img.shields.io/badge/Live-View-brightgreen)](https://productmanage-9wum.onrender.com)

ProductMag is a modern **React + Vite** web application for managing products efficiently. It features a clean and minimal setup, optimized for fast development with Hot Module Replacement (HMR) and ESLint rules.

## Features
- Add, edit, and delete products.
- Minimal React + Vite setup for fast performance.
- ESLint integrated for clean code.
- Ready for production with TypeScript compatibility.
- Responsive design for desktop and mobile.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/codewithharsharma2004/ProductMagNew.git
cd ProductMagNew
Install dependencies:
npm install
Start the development server:
npm run dev
Open your browser and go to http://localhost:5173 (default Vite port).
